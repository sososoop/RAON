2 헷갈리는 짝꿍 단어 — 알맞은 것 고르기

문장에 맞는 단어에 동그라미 하세요. 뜻을 잘 생각해요!

  1. The lion is a fierce ( predator / protect ). 사자는 사나운 ___이다.
  2. There are ( similar / several ) reasons to visit Mars. 화성에 갈 ___ 이유가 있다.
  3. Mars has a day length ( similar / several ) to Earth's. 화성의 하루 길이는 지구와 ___.
  4. The owl is ( wise / wisdom ). 올빼미는 ___ (형용사 자리).
  5. The owl is a symbol of ( wise / wisdom ). 올빼미는 ___의 상징이다.
  6. The fish tried to ( hide / escape ) from the net. 물고기는 그물에서 ___하려 했다.
  7. Turtles ( hide / escape ) inside their shells. 거북은 등딱지 안에 ___.
  8. The octopus has an ( invisible / amazing ) ability to change color. 문어는 ___ 색 바꾸기 능력이 있다.
